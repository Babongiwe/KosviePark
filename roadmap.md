# KovsiePark roadmap

- [x] Login, registration, forgot/reset password, 20-minute inactivity timeout
- [x] Login lockout (4 failures = 30 s, 8 = 5 min, 12 = locked until password reset)
- [x] Role-based navigation bar and notification bell for every role
- [x] Student / Staff: permits, renewal, vehicles, profile, fines, parking zones
- [x] Staff: register visitor
- [x] Visitor: 5-step wizard with validation per step, temporary permit, cancel/lookup
- [x] Admin: applications (reject reason required), permits, zones, visitor reservations, send notifications
- [x] Security: vehicle check, ALPR simulation, grace periods, violations and fines
